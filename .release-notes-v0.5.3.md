## v0.5.3 — 2026-10-15

### English

#### Added

- `mobile-vant` includes the same ECharts set as `admin-desktop`: line, bar, donut, mixed, funnel, gauge, heatmap, and map. Open either pack on the sketch board and place those charts.
- Chart source lives in `.html-prototype/pack-plugins/echarts/` and is stamped into each host pack with `node skills/ui-pack-maintain/scripts/stamp-chart-plugin.mjs`. The plugin is not a third installable pack.

#### Changed

- `ui-pack-maintain` finds installed packs the same way prototype generation does: `--pack-root` / `HTML_PROTOTYPE_PACK_ROOT`, then `.html-prototype/packs/` upward from the working directory, then `~/.html-prototype/packs/`. `list-packs.mjs` prints that list.
- Sketch charts load scripts from the open pack and use that pack's class prefix and theme tokens. Mobile charts use `mv-` and a phone width; desktop charts stay on `ui-` and can still sit in `data.card`.
- Pack install registry pins `ref: v0.5.3`.

#### Install / update

Re-install or update both skills, then reinstall both official packs so sketch and `resolve-pack` see the chart components:

```bash
npx skills add https://github.com/Lisuiwen/ai-html-annotation --skill html-prototype-build
npx skills add https://github.com/Lisuiwen/ai-html-annotation --skill ui-pack-maintain
node <skill-root>/scripts/install-pack.mjs --list-remote
node <skill-root>/scripts/install-pack.mjs --pack=admin-desktop
node <skill-root>/scripts/install-pack.mjs --pack=mobile-vant
```

### 中文

#### 新增

- `mobile-vant` 带上与 `admin-desktop` 相同的 ECharts 图表：折线、柱、环、组合、漏斗、仪表、热力、地图。草图板打开任一包即可把这些图拖到画布上。
- 图表源在 `.html-prototype/pack-plugins/echarts/`，用 `node skills/ui-pack-maintain/scripts/stamp-chart-plugin.mjs` 打进宿主包。这个插件不能单独安装。

#### 变更

- `ui-pack-maintain` 与原型生成使用同一套包查找：`--pack-root` / `HTML_PROTOTYPE_PACK_ROOT`，然后从工作目录向上找 `.html-prototype/packs/`，再找 `~/.html-prototype/packs/`。`list-packs.mjs` 列出这些包。
- 草图板按当前打开的包加载图表脚本，并使用该包的类名前缀和主题色。移动端用 `mv-` 和手机宽度；桌面端仍用 `ui-`，图表仍可放进 `data.card`。
- 安装 registry 固定 `ref: v0.5.3`。

#### 安装 / 更新

请重新安装或更新两个 Skill，并重新安装两个官方包，草图板和 `resolve-pack` 才会看到图表组件：

```bash
npx skills add https://github.com/Lisuiwen/ai-html-annotation --skill html-prototype-build
npx skills add https://github.com/Lisuiwen/ai-html-annotation --skill ui-pack-maintain
node <skill-root>/scripts/install-pack.mjs --list-remote
node <skill-root>/scripts/install-pack.mjs --pack=admin-desktop
node <skill-root>/scripts/install-pack.mjs --pack=mobile-vant
```
